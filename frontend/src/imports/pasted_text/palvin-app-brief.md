Build a COMPLETE, FULLY INTERACTIVE WEB APPLICATION called **PALVIN** for a couple: **Alvin × Paoi**.

IMPORTANT:
This is NOT a static design, NOT a presentation, NOT a wireframe, and NOT a visual-only prototype.

Build it as a **real interactive web app experience** inside Figma Make. Every major button, tab, navigation item, form, modal, card, menu, and interaction must work and update the UI state appropriately.

The user must be able to navigate through the entire application and interact with realistic data.

==================================================

1. PRODUCT CONCEPT
   ==================================================

PALVIN is a private social/lifestyle application exclusively for two people:

**Alvin ❤️ Paoi**

The concept combines:

* Instagram-style private social feed
* Couple memories
* Relationship timeline
* Shared fund
* Expense tracking
* Savings goals
* Love notes
* Couple calendar
* Daily mood
* Future goals
* Couple profile

The product should feel like:

**Instagram + Couple Journal + Shared Wallet + Private Diary**

but with a unique romantic identity.

Core emotional concept:

> "Our little world, made for two."

Only Alvin and Paoi exist in the application.
